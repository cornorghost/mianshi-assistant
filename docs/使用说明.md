# 面试助手使用说明

对应 0.6.6 及后续兼容版本。项目叫“面试助手”，应用、窗口和可执行文件叫 `chatbox`，这是同一个软件。数据目录保留历史名称 `interview-copilot-local` 以兼容旧会话。

## 1. 准备与启动

### 安装包

从本仓库 Releases 下载对应架构的 ZIP，完整解压，不要只复制 EXE 或移动 Mac 应用内部文件。

- Windows x64：双击 `chatbox.exe`。
- Apple 芯片 Mac 选 arm64 包，Intel Mac 选 x64 包。
- Mac 首次：把整个解压目录放在本机可写位置，右键打开同目录 `启动chatbox.command`。脚本仅对同目录 `chatbox.app` 移除隔离标记并按需进行本机临时签名；这不是 Apple 开发者签名或公证。之后可直接打开应用。

升级可使用新目录解压，历史保存在独立用户数据目录。

### Codex

先安装并登录 Codex 桌面版，或安装 CLI 并执行 `codex login`。应用不包含登录凭据，不替你创建账户。

自动查找桌面版内置 CLI、PATH、npm 等常见位置。Mac 包括 `/Applications/Codex.app`、`~/Applications/Codex.app` 及 Homebrew / npm / nvm 常见目录。

找不到时，在设置的“Codex CLI 路径”选择 CLI 可执行文件或 `Codex.app`，点击“保存路径并检测”。支持 `~/` 和外层引号，保存后重启仍保留。

也支持 `INTERVIEW_CODEX_PATH`、`CODEX_CLI_PATH` 环境变量。Mac 从 Finder 双击启动不一定继承终端环境，直接保存路径更可靠。模型留空使用账户默认模型；截图需要所选模型支持图片输入。

### 百炼语音

在阿里云百炼控制台的北京地域创建自己的 API Key，确认账户允许调用 `paraformer-realtime-v2`。这里需要 `sk-` 开头的 DashScope Key，不是阿里云 AccessKey 或 NLS AppKey。

设置 → “百炼 · 流式识别” → 粘贴 Key → 保存。业务空间 ID、热词表 ID 为选填，无已有配置时留空。非默认空间需与 Key 权限和地域匹配。

Key 使用 Electron safeStorage 调用操作系统加密后保存。加密不可用时会报错，不退回明文保存。也可使用启动进程的 `DASHSCOPE_API_KEY` 环境变量；已有保存的 Key 优先。

程序不自动读取项目 `.env`。安装包没有默认共享 Key；旧 Windows 用户可沿用本机已保存的 Key，换设备需自行配置。

### 系统权限

“系统声音”转写电脑播放的声音，“麦克风”转写麦克风输入。Mac 按提示授予屏幕 / 系统声音录制权限，需要麦克风时授予麦克风权限；更改后可能需完全退出应用再打开。Mac 系统声音建议使用 macOS 14.2 或更高版本。

## 2. 监听与自动回答

1. 顶部显示 Codex 已连接，选择正确声音来源，点击“开始监听”。
2. 确认按钮旁显示“自动回答 开”，点击可立即切换并保存。
3. 转写草稿随识别结果修订，最终句进入完整转写；相邻句默认等待 1 秒合并后形成问题，自动排队回答。
4. 左侧选择问题，右侧查看对应回答；生成期间收到的新问题会保存并排队。

“多句合并等待”可选 0.5–2.5 秒，短等待更快，长等待能包含更多连续上下文。按停顿归并不保证语义分段或区分发言人。简单寒暄可能不触发回答，但仍保留转写。

关闭时显示“仅转写 · 需手动发送”。重新开启从后续语句开始处理，不重发全部旧转写。手动输入可点击箭头或在输入框按 Ctrl + Enter。

暂停会等待尾音和最终结果。连接异常时保留已收到的数据，不自动重传整场录音。准确率与延迟需在自己的设备、声音和网络环境中验证。

## 3. 截图提问

默认“两点快捷键”方式：

1. 把系统指针移到区域第一个角，按 Ctrl + Shift + S（Mac：Command + Shift + S）。
2. 移到对角，再按一次相同快捷键。
3. 截图立即保存；开启“截图完成后自动提问”时自动排队回答。

两点方式不覆盖全屏框选层，不接管系统指针。Ctrl / Command + Shift + Esc 可取消选择；设置也可切换拖拽框选。

**截图自动提问与语音自动回答是独立开关。** 关闭前者时截图仍保存，可手动发送。Mac 系统 Command + Shift + 4 的截图不会自动导入，请使用应用快捷键。

每道截图题绑定独立图片，在问题、回答和历史中可查看原图并放大。顶部状态提示保存、排队、生成、失败或阻止原因。

## 4. 参考项目与回答要求

设置中可填写简历 / 岗位 / 项目资料及回答要求，调整语言、长度和格式。

“本场参考项目文件夹”为选填：留空使用通用模式；有效目录作为 Codex 工作目录，模型按需调用列目录、搜索和读取工具；路径不存在或不可读时提示并回退通用模式。应用不在提问前扫描整个项目并拼入提示词。

内置文件工具限制在选定目录内，排除常见凭据文件、依赖和构建目录，不提供写文件功能。这无法自动识别代码中的所有机密；模型读取的内容会交给其配置的模型服务，请仅选择有权提供的资料。第三方 Codex 配置可能影响行为，不应把应用当作完全隔离环境。

## 5. 多会话与导出

顶部可切换、重命名和新建会话，新会话不会清空旧会话。“结束并归档”会等待尾句和回答完成，历史中可查看或继续已归档会话。

保存完整转写、提问、对应原始句、来源、截图、回答、时间与排队 / 生成 / 完成 / 中断状态。部分回答也持续落盘。异常退出后保留未完成状态，不自动重试消耗模型额度。

“导出”生成 Markdown 和配套 `-assets` 图片目录。移动或分享时两者必须一起移动。导出可能包含简历、代码和交流内容，分享前自行检查。

## 6. 数据位置与隐私

| 系统 | 用户数据目录 |
| --- | --- |
| Windows | `%APPDATA%/interview-copilot-local` |
| macOS | `~/Library/Application Support/interview-copilot-local` |

- `settings.json`：普通设置、资料和项目路径，明文保存。
- `bailian-key.bin`：操作系统加密的 Key，不应上传或复制给他人。
- `speech-archive/interviews`：会话 JSON、Markdown、图片附件。
- `speech-archive/bailian`：百炼模式录音与识别记录；本地识别也保存自己的音频与任务记录。

数据不自动删除。删除应用不等于删除用户数据；清理前先退出并备份需要保留的记录。

百炼模式将声音发给百炼；问题、资料、截图及按需读取的代码经 Codex 发送至其配置的模型服务。本地 Whisper 仅让语音识别在本机进行，回答仍可能使用远程服务。软件不附带服务额度。打开程序和保存 Key 不启动百炼任务，开始监听才连接。

## 7. 窗口与快捷键

支持置顶、35%–100% 不透明度和穿透。开启穿透后保持置顶，顶部工具栏可操作，正文点击和滚动交给下层窗口；设置、历史、原图查看暂时恢复交互，返回后继续穿透。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl / Command + Shift + S | 标记两点截图 / 触发截题 |
| Ctrl / Command + Shift + Esc | 取消截题 |
| Ctrl / Command + Shift + Space | 提交当前问题及附图 |
| Ctrl / Command + Shift + P | 切换穿透 |
| Ctrl / Command + Shift + H | 隐藏 / 显示应用 |
| Ctrl + Enter | 输入框内提交 |

快捷键可能与其他应用冲突。捕获保护使用系统机制，效果取决于系统与会议软件，不能保证所有录屏或共享方式下隐藏。穿透只影响本机交互。

## 8. 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 找不到 Codex | 安装并登录；设置中保存 CLI 文件或 Codex.app 路径，再检测 |
| Key 无效或无权限 | 核对北京地域、模型权限、额度、业务空间，不要填 NLS AppKey |
| 有文字但不自动回答 | 检查“自动回答”是否开启；已归档会话先继续 |
| 截图保存但没回答 | 检查独立“截图完成后自动提问”、Codex 连接与顶部截图状态 |
| 录不到声音 | 核对系统声音 / 麦克风来源、权限、实际播放声音；Mac 改权限后重启 |
| 多句话被分开或等待久 | 调整多句合并等待；声学停顿和识别结果也有影响 |
| 穿透后点不到正文 | 顶部“穿透”或 Ctrl / Command + Shift + P 关闭 |
| 导出图片不见 | Markdown 与同名附件目录保持在一起 |

## 9. 源码与本地识别备用方案

```sh
npm ci
npm start
```

需要 Node.js 22 或更新的受支持版本。仍需自己的 Codex 登录、百炼 Key 和系统权限；测试使用模拟服务，不含共用凭据。

若安装停在 Electron 下载，可在当前终端设置镜像后重新执行 `npm ci`：

```powershell
# Windows PowerShell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
npm ci
```

```sh
# macOS 终端
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm ci
```

本地 Whisper 不是解压即用功能。Windows 源码环境安装 Python 3.11 后，可运行“安装语音组件.cmd”，安装依赖并下载模型，再选“本地 Whisper · 备用”。安装脚本为 Windows 编写；Mac 包不自带 Python、模型或本地语音安装流程。常规使用推荐百炼。

`npm run check` 检查语法，`npm test` 运行测试；`npm run pack` 构建三个平台 ZIP，需要 Python 3 及 Electron 下载网络。不要提交 `.venv`、`.models`、录音或个人配置。
