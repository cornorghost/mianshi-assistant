# 面试助手

用于面试练习与交流辅助的桌面项目：实时语音转写、自动整理问题并生成回答、区域截图解题，以及可持续保存的多会话记录。支持 Windows 和 macOS。

## 为什么程序叫 chatbox？

**面试助手是项目名称，`chatbox` 是应用名称。** 窗口标题、可执行文件、Mac 应用和下载包沿用 `chatbox`，两者指同一个项目，不需要另装一个“面试助手”。该名称不表示与其他同名产品有关联。

为兼容已有版本，会话与配置目录继续使用 `interview-copilot-local`，更新版本无需搬迁历史数据。

## 功能

- 百炼流式语音识别，保留中间结果修订和完整转写；支持系统声音或麦克风。
- 根据停顿合并连续语句，识别问题后自动排队回答；语音自动回答与截图自动提问独立开关。
- 两点快捷键区域截图，保留系统指针；截图随会话保存，问题与回答左右展示。
- 通过本机 Codex 登录生成回答；可选项目文件夹，由模型按需调用只读文件工具。
- 新建、切换、重命名、归档和继续会话；导出 Markdown 及对应截图附件。
- 置顶、透明度、鼠标穿透和窗口捕获保护。

## 下载与首次使用

在本仓库 **Releases** 下载对应 ZIP，并解压完整目录：

| 系统 | 下载包 | 启动方式 |
| --- | --- | --- |
| Windows x64 | `chatbox-版本-Windows-x64.zip` | 双击 `chatbox.exe` |
| Mac Apple 芯片 | `chatbox-版本-Mac-arm64.zip` | 首次右键打开 `启动chatbox.command` |
| Mac Intel | `chatbox-版本-Mac-x64.zip` | 首次右键打开 `启动chatbox.command` |

云端识别版自带运行时，无需另装 Node.js 或 Python。Mac 包没有 Apple 开发者签名或公证；启动脚本会为同目录应用移除隔离标记、执行本机临时签名，然后启动。请放在本机可写目录中运行。

1. 安装并登录 Codex 桌面版，或安装 Codex CLI 后执行 `codex login`。
2. 打开 `chatbox` → 设置 → 选择“百炼 · 流式识别”，填写自己的**百炼北京地域 API Key**，保存。
3. 等待顶部“Codex 已连接”。找不到 CLI 时，在设置中选择 CLI 文件或 `Codex.app`，点击“保存路径并检测”。
4. 选择声音来源并开始监听，确认“自动回答 开”。截图用 Ctrl / Command + Shift + S，依次标记区域两个角。

详见 **[使用说明](docs/使用说明.md)**，包括权限、项目目录、会话导出、数据位置和故障排查。

## 数据与费用

项目不附带百炼密钥、Codex 登录、简历或用户会话。每位使用者独立配置自己的账户，费用按服务商实际规则收取。

| 数据 | 处理位置 |
| --- | --- |
| 百炼模式下选择的声音 | 发送至百炼，并在本机保留录音及转写 |
| 提问、截图、填写的资料、按需读取的项目片段 | 交给本机 Codex，再由其配置的模型服务处理 |
| 会话历史、截图、普通设置 | 保存在本机，属于明文数据 |
| 百炼 API Key | 操作系统加密后保存在本机；也可从 `DASHSCOPE_API_KEY` 读取 |

“本机 Codex”不代表模型离线运行。查看历史不会自动重试或调用模型。打开应用、保存 Key 不会启动百炼识别任务，开始监听才会连接。

请遵守所在场景的录音、屏幕共享与辅助工具使用约定。窗口保护效果取决于操作系统和会议软件，不能保证所有共享方式都不可见。鼠标穿透只影响本机点击行为。

## 从源码运行

需要 Node.js 22 或更新的受支持版本、npm，以及已登录的 Codex。常规百炼模式无需 Python。

```sh
npm ci
npm start
```

首次仍需配置自己的百炼 Key、Codex 和系统权限。不要将密钥写入源码或提交到 Git；应用不自动加载 `.env` 文件。

```sh
npm run check
npm test
```

构建三个平台的 ZIP：

```sh
npm run pack
```

构建额外需要 Python 3 和 Electron 下载网络。产物位于 `dist/releases/版本/`，附 `SHA256SUMS.txt`。跨平台打包成功不等于全部平台都已实机验证。

## 实现与限制

- 桌面：Electron；UI：原生 HTML / CSS / JavaScript。
- 语音：百炼 `paraformer-realtime-v2`，16kHz 单声道 PCM16 流式上传；本地 faster-whisper 为需要额外配置的备用方案。
- 模型：Codex App Server；参考项目工具提供列目录、搜索和读取，不提供修改操作。
- 问题分段按停顿与相邻语句归并，不保证准确语义分段，不提供说话人分离。
- Key 的系统加密不等于会话文件加密。不要将用户数据目录或导出会话上传到公共仓库。
- macOS 系统声音建议使用 14.2 或更高版本并授予系统权限；Mac 实机行为需要在目标设备确认。
